Fluxo de Implementação
1.1. Configuração Inicial e Entidades:Dependências e Modelo de Dados.Adicione as dependências do Spring Boot Starter Security e jjwt (Java JWT) no pom.xml.
Crie a entidade Usuario implementando UserDetails e um Enum para as Roles (ex: ROLE_ADMIN, ROLE_USER).
Java

public enum Role {
    ROLE_ADMIN,
    ROLE_USER
}
2.2. Repositório e UserDetailsService:Acesso aos Dados.Crie o UsuarioRepository com um método para buscar por login/email (findByLogin).
Implemente a interface UserDetailsService do Spring Security. Ela será usada pelo Spring para buscar o usuário no banco de dados durante o processo de autenticação.
3.3. Serviço de JWT (TokenService):Manipulação do Token.Crie uma classe utilitária para gerar e validar o token JWT. Ela deve ter dois métodos principais:
gerarToken(Usuario usuario): Cria o token assinado incluindo o login e as Roles do usuário nas claims.
validarToken(String token): Decodifica o token, verifica a assinatura e retorna o login do usuário.
4.4. Filtro de Autenticação (SecurityFilter):Interceptação de Requisições.Crie um filtro que herda de OncePerRequestFilter. A cada requisição HTTP recebida:
Extrai o token do cabeçalho Authorization: Bearer <token>.
Se o token for válido, recupera o usuário no banco.
Cria o objeto UsernamePasswordAuthenticationToken com as autoridades (roles) do usuário e salva no SecurityContextHolder.
5.5. SecurityConfigurations:Configuração do Spring Security.Crie a classe de configuração @Configuration e @EnableWebSecurity definindo a SecurityFilterChain:
Defina o gerenciamento de sessão como Stateless (SessionCreationPolicy.STATELESS).
Desabilite o csrf (desnecessário para APIs REST com JWT).
Configure a autorização das rotas usando hasRole ou hasAnyRole.
Registre o seu SecurityFilter para rodar antes do UsernamePasswordAuthenticationFilter.
6.6. Controller de Autenticação:Endpoints Públicos.Crie os endpoints /auth/login e /auth/register:
No registro, lembre-se de codificar a senha com PasswordEncoder (BCrypt) antes de salvar.
No login, autentique o usuário, chame o TokenService e retorne o JWT gerado no corpo da resposta.

Conexão com API externa:

1. Mapear o JSON de Resposta (DTOs)
Analise o JSON que a API externa devolve e crie records para representar essa estrutura.

Use a anotação @JsonProperty("nome_no_json") para mapear campos do JSON que possuem nomes diferentes das suas variáveis Java (ex: de bid para valorCompra).
2. Configurar o Cliente HTTP (RestClient)
No Spring Boot 3.2+, o RestClient é a ferramenta padrão para requisições síncronas.

Defina a URL base da API externa (ex: [https://economia.awesomeapi.com.br/json/last](https://economia.awesomeapi.com.br/json/last)).
Você pode instanciar o RestClient diretamente no serviço via RestClient.builder().baseUrl(...).build() ou prover um @Bean de RestClient.Builder.
3. Criar a Classe de Serviço (Service)
A classe anotada com @Service vai conter a regra de integração:

Monte a requisição usando o método HTTP desejado (.get(), .post(), etc.) e a URI relativa.
Use o .retrieve() para executar a chamada.
Trate erros de resposta com .onStatus(), lançando exceções de negócio personalizadas se necessário.
Converta o corpo da resposta no seu DTO usando .body(MeuDto.class).
Extraia e valide os dados recebidos antes de retornar.
4. Configurar as Permissões de Acesso (SecurityConfigurations)
Ajuste as regras do Spring Security para definir quem pode acessar o recurso:

Libere a rota pública com .permitAll() ou exija autenticação e roles específicas (ex: .hasAnyRole("USER", "ADMIN")).
5. Expor o Endpoint (Controller)
Crie um @RestController que injeta o seu Service:

Mapeie a rota HTTP (ex: @GetMapping("/api/cotacoes/dolar")).
Invoque o serviço de integração e devolva os dados encapsulados em um ResponseEntity.

1. Usar a extensão "Gitingest" no Terminal do IntelliJ (A mais rápida 🚀)
O Gitingest (ou ferramentas similares de CLI como code2prompt ou files-to-prompt) varre o diretório do seu projeto, respeita o .gitignore (para não pegar as pastas .idea, target ou build) e gera um único arquivo de texto com todo o código formatado.

Como fazer:
Abra o Terminal integrado do IntelliJ (Alt + F12 ou opção Terminal no rodapé).
Se você tem o Python instalado, execute no terminal:

Bash

pip install gitingest
Depois, dentro da pasta do seu projeto, rode:

Bash

gitingest .
